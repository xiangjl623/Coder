## 推荐复习顺序

1. 确认 [C 语言基础](../../../languages/c/) 已掌握（至少指针、函数、结构体）
2. 按 [学习手册](../../../languages/cpp/学习手册/C++从入门到精通.md) 过一遍核心章节
3. 对照上方考点速览，薄弱项回看对应速查
4. 刷 [按章题库](../../../languages/cpp/题库/C++题库.md) 并对照参考答案
