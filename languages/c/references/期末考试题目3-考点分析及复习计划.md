## 二、高频易错点 TOP 10

1. **`&&` / `||` 短路求值** — 左操作数能确定结果时，右操作数不执行
2. **`=` 与 `==` 混淆** — `while(k=1)` 是赋值，永远为真，形成死循环
3. **`sum` 未初始化** — 局部变量不初始化，值为随机垃圾值
4. **整数除法陷阱** — `5/9=0`，必须用 `5.0/9.0`
5. **数组整体赋值** — `a={1,2,3}` 只能在定义时使用，之后非法
6. **字符串结束符** — 是 `'\0'`（ASCII 0），不是 `'0'`（ASCII 48）
7. **数组下标越界** — `a[10]` 有效下标是 0~9
8. **宏定义文本替换** — `#define M N+1` 不是先算值再替换
9. **函数嵌套定义** — C语言不允许函数内定义函数
10. **`sizeof` vs `strlen`** — `sizeof` 算数组总字节，`strlen` 算字符串长度（不含 `'\0'`）

```c
// 二维数组部分初始化
int a[3][4] = {{1},{5},{9}};
// 结果：第一列分别为1,5,9，其余为0

// 行优先存储 - 第10个元素
int a[3][7];  // a[1][2] 是第10个元素

int a[3][3], *p = &a[0][0];
for (int i = 0; i < 9; i++)

// 指针找最大值
int findmax(int *a, int n) {
    int *p, *s;
    for (p = a, s = a; p < a + n; p++)
        if (*p > *s) s = p;
    return *s;
}
```

**改错题常见错误类型速查：**

| 错误类型 | 示例 |
|----------|------|
| 变量未定义/未初始化 | `sum` 未赋初值0 |
| 类型不匹配 | `float sum` 但用 `%d` 输出 |
| 下标越界/错误 | `s[s1-i]` 应为 `s[s1-1-i]` |
| 结束符错误 | `'0'` 应为 `'\0'` |
| 复制方向错误 | 应 `s1[i] = s2[j]` 而非 `s2[j] = s1[i]` |
| 循环条件错误 | `&&` 应为 `\|\|`（杨辉三角边界） |
| 变量声明语法 | `char a, *p, int i;` 应分开声明 |
