# C 语言题库设计

> 日期：2026-07-26  
> 状态：已确认待实现

## 目标

基于 `languages/c/references/` 参考资料，整理一份按章节知识点编排的 C 语言题库，输出为单文件，便于系统复习与对照答案。

## 输出

| 项 | 约定 |
|----|------|
| 路径 | `languages/c/题库/C语言题库.md` |
| 形式 | 单 Markdown 文件 |
| 与现有 `exams/` 关系 | 并存；本题库按知识点分章，`exams/` 保持期末题型分册 |

## 章节划分

对齐 `references/` 的 14 个速查主题：

1. 程序基础  
2. 数据类型与常量  
3. 运算符  
4. 流程控制  
5. 函数  
6. 指针  
7. 数组  
8. 字符串  
9. 结构体与枚举  
10. 预处理  
11. 输入输出  
12. 文件操作  
13. 动态内存  
14. 常用库函数  

## 文件结构（方案 1：章内先题后答）

全文结构：

```text
# C 语言题库
## 使用说明
## 目录

## 第 N 章 · 主题名
### 本章知识点速览
### 一、题目
### 二、参考答案与解析
### 三、本章知识点总结
```

每章内先给出题目，再给出参考答案与解析，最后给出该章知识点总结。不做全书「上册题目 / 下册答案」拆分。

## 题量与题型

- 每章约 15～20 题，全书约 210～280 题。
- 配比（可按章节侧重微调）：
  - 选择题 6～8 题
  - 填空题 3～5 题
  - 读程序写结果 3～4 题
  - 简答或小编程 2～3 题
- 指针、数组、字符串、函数、文件、动态内存等章可略增读程序与编程题；程序基础、预处理等章可略增选择与填空。

## 取材规则

按优先级：

1. `references/` 速查分册与 `C语言常用语法汇总.md` 中的知识点  
2. `references/` 下期末真题、常考编程题中的相关考点  
3. 现有 `exams/` 可复用题目：改写去重后按章归入，不整卷照搬  

## 质量约定

- 题目与答案分节清晰；答案含简短解析（说明为何正确 / 常见误区）。  
- 「本章知识点总结」提炼核心口诀、对照表或易错点，不整段复制速查原文。  
- 读程序与编程题中的代码片段应可编译、结果可验证（约定常见 32/64 位下的典型行为，必要时注明）。  
- 题号在章内连续；题型用小标题分组。  

## 非目标

- 不替换或删除现有 `exams/` 题库。  
- 不拆成多文件分章题库。  
- 不生成 PDF / PPT。  
- 不要求自动阅卷或在线判题。  

## 实现顺序建议

1. 创建 `languages/c/题库/` 与题库文件骨架（封面、使用说明、目录、14 章空模板）。  
2. 按章填充：速览 → 题目 → 答案解析 → 知识点总结。  
3. 通读检查题号、答案对应、代码结果。  
4. 在 `languages/c/README.md` 内容索引中增加题库入口（可选，实现时一并完成）。
