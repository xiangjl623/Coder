## 第 1 章 · 程序基础

### 本章知识点速览
- 编译四阶段：预处理 → 编译 → 汇编 → 链接
- `main` 是程序入口，通常 `return 0` 表示正常结束
- 标识符：字母/`_` 开头，区分大小写，不能是关键字
- `.c` 放实现，`.h` 放声明/宏/类型；`#include` 引入头文件
- 注释：`//`（C99）与 `/* */`（不可嵌套）

### 一、题目

#### 选择题
1. 下列关于 C 语言编译流程的说法，正确的是：
A. 预处理直接生成可执行文件

C. 编译阶段将 C 代码翻译为汇编代码
D. 汇编阶段合并目标文件与库

2. 程序的入口函数通常是：

4. 关于 `.c` 与 `.h` 文件，正确的是：
A. `.h` 中通常写函数的具体实现

C. `.c` 存放实现，`.h` 存放声明，由 `#include` 引入
D. 两者完全等价，可随意互换

5. 下列关于注释的说法，错误的是：

A. `main`

### 二、参考答案与解析

1. **答案：C**  
   解析：预处理处理 `#` 指令；编译生成汇编；汇编生成目标文件；链接生成可执行文件。

2. **答案：B**  
   解析：C 程序从 `main` 开始执行。

3. **答案：C**  
   解析：`_total` 合法；不能以数字开头，不能含 `-`，不能是关键字。

4. **答案：C**  
   解析：约定是实现与声明分离：`.c` 实现，`.h` 声明。

5. **答案：B**  
   解析：`/* */` 注释不能嵌套。

6. **答案：C**  
   解析：`sizeof` 是关键字；`main`、`printf` 是标识符/库函数名。

7. **答案：C**

9. **答案：.c；.h**

10. **答案：字母；下划线 `_`**  
    解析：首字符不能是数字。

11. **答案：正常（成功）**

13. **答案：**
```text
3 5
```
    解析：标识符区分大小写，`Sum` 与 `sum` 是两个变量。

14. **答案：**
```text
C
```
    解析：前两行输出被注释掉，只打印 `C`。

15. **答案要点：**  
    预处理：处理 `#include`/`#define` 等，常见产物 `.i`；编译：C→汇编，`.s`；汇编：汇编→机器码目标文件，`.o`/`.obj`；链接：合并目标文件与库，生成可执行文件。

16. **答案要点：**  
    关键字由语言保留，有固定语法含义，用作变量名会导致语法错误。示例：用 `my_int`、`ret_val` 等代替。

### 三、本章知识点总结
| 要点 | 速记 |
|------|------|
| 编译流程 | 预→编→汇→链 |
| 入口 | `main`，`return 0` 成功 |
| 标识符 | 字母/`_` 开头，区分大小写 |
| 文件 | `.c` 实现 / `.h` 声明 |
| 注释 | `//` 与 `/* */`，后者不可嵌套 |

## 第 2 章 · 数据类型与常量

### 本章知识点速览
- 基本类型：`char/short/int/long/long long/float/double/void`
- 常见 64 位：`sizeof(int)=4`，`sizeof(double)=8`，`sizeof(char)=1`
- 进制：八进制前缀 `0`，十六进制 `0x`；字符 `'A'`，字符串 `"hi"`（含 `\0`）
- `signed/unsigned`、`const`；局部未初始化值不确定，静态/全局默认为 0
- 转义字符与隐式/显式类型转换

#### 简答或编程

### 二、参考答案与解析

1. **答案：C**  
   解析：常见 32/64 位桌面环境下 `int` 多为 4 字节。

2. **答案：A**  
   解析：`0xFF = 15*16+15 = 255`。

3. **答案：B**  
   解析：`unsigned` 只表示非负数，范围从 0 起。

4. **答案：C**  
   解析：浮点赋给整型发生隐式截断，小数部分丢弃。

5. **答案：B**  
   解析：单引号表示字符常量；双引号是字符串。

6. **答案：C**  
   解析：自动存储期局部变量未初始化则值不确定。

7. **答案：C**  
   解析：`\n` 换行，`\t` 制表，`\\` 反斜杠，`\0` 空字符。

8. **答案：0；0x（或 0X）**  
   解析：如 `0377`、`0xFF`。

9. **答案：3；`\0`**  
   解析：`'H'`、`'i'`、`'\0'`。

10. **答案：1；8**  
    解析：`char` 恒为 1；`double` 常见为 8。

11. **答案：`(int)3.9`；3**  
    解析：显式强制转换，向零截断。

12. **答案：**
```text
4 1
```
    解析：常见 64 位下 `int` 4 字节，`char` 1 字节。（若用 `%zu` 打印 `sizeof`）

13. **答案：**
```text
255 255
```
    解析：`0377` 与 `0xFF` 均为 255。

14. **答案：**
```text
A 65
3
```
    解析：`'A'` ASCII 为 65；`(int)3.9` 截断为 3。

15. **答案要点：**  
    `#define` 为预处理文本替换，无类型；`const` 有类型、受编译器类型检查，通常更安全。

16. **答案要点：**  
    `signed` 可负可正；`unsigned` 仅非负。长度/个数不会为负，用无符号可扩大正数范围并表达语义。

### 三、本章知识点总结
| 类型/写法 | 要点 |
|-----------|------|
| `int` / `double` | 常见 4 / 8 字节 |
| `0` / `0x` | 八进制 / 十六进制 |
| `'A'` / `"A"` | 字符 / 字符串（含 `\0`） |
| 初始化 | 局部未初始化不定；静态/全局默 0 |
| 转换 | 隐式自动；显式 `(type)` |

## 第 3 章 · 运算符

### 本章知识点速览
- 整数除法截断：`5/2=2`；浮点参与则得浮点结果
- 前缀/后缀自增：`++i` 先加后用，`i++` 先用后加
- 逻辑短路：`&&` 左假不算右，`||` 左真不算右
- 位运算：`& | ^ ~ << >>`；注意与逻辑运算区分
- 优先级：单目→算术→移位→关系→位→逻辑→条件→赋值；`==` 与 `=` 易混

### 一、题目

#### 选择题
1. 表达式 `5 / 2` 的值是：
A. 2.5
B. 2
C. 3
D. 2.0

2. 设 `int i = 3;`，则表达式 `i++` 的值与之后 `i` 分别为：
A. 4 和 4
B. 3 和 4
C. 4 和 3
D. 3 和 3

3. 关于 `&&` 短路，下列正确的是：
A. 左边为真才不算右边
B. 左边为假则不算右边
C. 两边一定都会计算
D. 只用于位运算

4. `int a = 5, b = 3;` 则 `a & b` 的结果是：
A. 1
B. 7
C. 6
D. 0

5. 下列优先级最高的是：
A. `+`
B. `*`（乘法）
C. `=`
D. `&&`

6. `if (x = 0)` 与 `if (x == 0)` 的区别是：
A. 两者完全相同
B. 前者赋值，条件恒为假；后者比较是否等于 0
C. 前者比较，后者赋值
D. 两者都会导致编译错误

7. `a > b ? a : b` 的含义是：
A. 求 a 与 b 的和
B. 若 a>b 取 a，否则取 b
C. 位运算
D. 强制类型转换

#### 填空题
8. `5.0 / 2` 的结果是 ______；`5 % 2` 的结果是 ______。
9. 设 `int i = 1;`，执行 `int x = ++i;` 后，`x` 为 ______，`i` 为 ______。
10. 表达式 `0 && (1/0)` 不会触发除零，原因是 ______。
11. `a << 2` 在忽略溢出时约相当于把 `a` 乘以 ______。

#### 读程序写结果
12. 写出程序输出：

```c
#include <stdio.h>
int main(void) {
    int a = 5, b = 2;
    printf("%d %d\n", a / b, a % b);
    printf("%.1f\n", a / 2.0);
    return 0;
}
```

13. 写出程序输出：

```c
#include <stdio.h>
int main(void) {
    int i = 1, j = 1;
    int a = i++;
    int b = ++j;
    printf("%d %d %d %d\n", a, i, b, j);
    return 0;
}
```

14. 写出程序输出：

```c
#include <stdio.h>
int main(void) {
    int x = 0, y = 5;
    int r1 = x && (++y);
    int r2 = x || (++y);
    printf("%d %d %d\n", r1, r2, y);
    return 0;
}
```

15. 写出程序输出：

```c
#include <stdio.h>
int main(void) {
    int a = 6, b = 3;
    printf("%d %d %d\n", a & b, a | b, a ^ b);
    return 0;
}
```

#### 简答或编程
16. 解释为什么写条件判断时推荐 `if (x == 0)` 而不是 `if (x = 0)`。
17. 用一句话说明运算符优先级记忆口诀，并指出逗号运算符相对赋值的优先级高低。

### 二、参考答案与解析

1. **答案：B**  
   解析：两个整数相除结果仍为整数，向零截断。

2. **答案：B**  
   解析：后缀自增表达式值为加之前的值，随后 `i` 变为 4。

3. **答案：B**  
   解析：`&&` 左操作数为假即可确定整体为假，右边不计算。

4. **答案：A**  
   解析：`5` 为 `101`，`3` 为 `011`，按位与得 `001`，即 1。

5. **答案：B**  
   解析：乘法高于加、逻辑与、赋值。

6. **答案：B**  
   解析：`=` 赋值，`x=0` 表达式值为 0（假）；`==` 才是相等比较。

7. **答案：B**  
   解析：条件运算符：条件真取第二项，假取第三项。

8. **答案：2.5；1**  
   解析：有浮点则浮点除；`%` 为取余。

9. **答案：2；2**  
   解析：前缀先加，表达式值与变量均为加后值。

10. **答案：逻辑与短路，左边为假不再计算右边**  
    解析：短路求值是重要考点。

11. **答案：4**  
    解析：左移 1 位 ×2，左移 2 位 ×4。

12. **答案：**
```text
2 1
2.5
```
    解析：整数除/取余；`2.0` 触发浮点除。

13. **答案：**
```text
1 2 2 2
```
    解析：`a=i++` 得 1 后 i=2；`b=++j` 先加得 2。

14. **答案：**
```text
0 1 6
```
    解析：`x&&(++y)` 因 x=0 短路，y 仍 5；`x||(++y)` 会算右边，y 变为 6，结果为真 1。

15. **答案：**
```text
2 7 5
```
    解析：`6=110`，`3=011`；与=010(2)，或=111(7)，异或=101(5)。

16. **答案要点：**  
    `=` 是赋值，容易误写成恒假/恒真条件且改变变量；`==` 才是比较。有的风格写 `if (0 == x)` 可让误写 `=` 更易被编译器发现。

17. **答案要点：**  
    口诀：单目→算术→移位→关系→位运算→逻辑→条件→赋值→逗号。逗号优先级低于赋值。

### 三、本章知识点总结
- 整除截断；要小数就让一侧为浮点
- `++i` / `i++`：先加后用 / 先用后加
- `&&` `||` 有短路；`&` `|` 是位运算、无短路
- `==` 比较，`=` 赋值，条件里别写错
- 优先级拿不准就加括号

## 第 4 章 · 流程控制

### 本章知识点速览
- `if-else` 做范围/条件分支；`switch` 做整型等值多路分支（注意 `break`）
- `for` 适合已知次数；`while` 先判后执；`do-while` 至少执行一次
- `break` 跳出当前循环/`switch`；`continue` 结束本轮进入下一轮
- 多条语句作分支/循环体必须用 `{}`

### 一、题目

#### 选择题
1. `switch` 的 case 标签后面应当是：
A. 变量
B. 整型常量表达式
C. 任意表达式
D. 浮点常量

2. 关于 `do-while`，正确的是：
A. 可能一次也不执行
B. 至少执行一次
C. 不能使用 `break`
D. 条件写在循环体开头

3. `for (int i = 0; i < 3; i++)` 循环体执行次数是：
A. 2
B. 3
C. 4
D. 0

4. `continue` 的作用是：
A. 结束整个程序

## 第 6 章 · 指针

### 本章知识点速览
- `&` 取地址，`*` 解引用；指针保存的是地址
- `p+1` 按元素大小移动，不是固定 1 字节
- 数组名多数情况下等价于首元素地址；`a[i]` 等价 `*(a+i)`
- `NULL` 表示空指针；解引用未初始化/悬空指针是未定义行为
- `const int *p` 不能改 `*p`；`int *const p` 不能改 `p` 的指向
