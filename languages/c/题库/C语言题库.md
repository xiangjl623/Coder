# C 语言题库

> 按 `references/` 14 个主题分章；每章先题目、后参考答案与知识点总结。  
> 取材自语法汇总、期末真题与常考编程题，适合系统复习。

## 使用说明

1. 建议按章顺序练习；也可按薄弱主题跳章。
2. 先独立完成「一、题目」，再对照「二、参考答案与解析」。
3. 「三、本章知识点总结」用于考前速记，勿跳过。
4. 读程序题默认在常见 64 位 GCC/MSVC 环境下验证；`sizeof` 等若有差异已在答案中注明。
