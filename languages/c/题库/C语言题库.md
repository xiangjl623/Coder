## 第 1 章 · 程序基础

### 本章知识点速览
- 编译四阶段：预处理 → 编译 → 汇编 → 链接
- `main` 是程序入口，通常 `return 0` 表示正常结束
- 标识符：字母/`_` 开头，区分大小写，不能是关键字
- `.c` 放实现，`.h` 放声明/宏/类型；`#include` 引入头文件
- 注释：`//`（C99）与 `/* */`（不可嵌套）

### 二、参考答案与解析

1. **答案：C**  
   解析：预处理处理 `#` 指令；编译生成汇编；汇编生成目标文件；链接生成可执行文件。

2. **答案：B**  
   解析：C 程序从 `main` 开始执行。

3. **答案：C**  
   解析：`_total` 合法；不能以数字开头，不能含 `-`，不能是关键字。

4. **答案：C**  
   解析：约定是实现与声明分离：`.c` 实现，`.h` 声明。

5. **答案：B**  
   解析：`/* */` 注释不能嵌套。

6. **答案：C**  
   解析：`sizeof` 是关键字；`main`、`printf` 是标识符/库函数名。

7. **答案：C**  
   解析：`-c` 表示只编译到目标文件（`.o`/`.obj`），不链接。

8. **答案：B**  
   解析：预处理产物常为 `.i`；编译 `.s`；汇编 `.o`；链接可执行文件。

9. **答案：C**  
   解析：C 无自动垃圾回收，`malloc` 等需手动 `free`。

10. **答案：B**  
   解析：尖括号通常搜系统路径；双引号通常先搜当前目录。

11. **答案：C**  
    解析：`goto` 是关键字，不能作标识符。

12. **答案：B**  
    解析：表达式有值；语句执行动作，常以 `;` 结束。

13. **答案：编译；链接**  
    解析：四阶段固定顺序：预处理→编译→汇编→链接。

14. **答案：.c；.h**  
    解析：源文件与头文件扩展名约定。

15. **答案：字母；下划线 `_`**  
    解析：首字符不能是数字。

16. **答案：正常（成功）**  
    解析：返回 0 通常表示成功，非 0 表示异常。

17. **答案：输出文件名（可执行文件名）**  
    解析：`-o` 指定生成目标名称。

18. **答案：复合**  
    解析：复合语句用 `{}` 组成语句块。

19. **答案：两**  
    解析：大小写敏感。

20. **答案：**
```text
Hello, C!
```
    解析：标准最小程序输出，`\n` 换行。

21. **答案：**
```text
3 5
```
    解析：标识符区分大小写，`Sum` 与 `sum` 是两个变量。

22. **答案：**
```text
C
```
    解析：前两行输出被注释掉，只打印 `C`。

23. **答案：**
```text
7
OK
```
    解析：先乘后加得 7，再输出 `OK`。

24. **答案：**
```text
20 10
```
    解析：内层块的 `a` 遮蔽外层；离开块后外层仍为 10。

25. **答案：**
```text
C Language
```
    解析：预处理用 `MSG` 替换为 `"C"`。

26. **答案要点：**  
    预处理：处理 `#include`/`#define` 等，常见产物 `.i`；编译：C→汇编，`.s`；汇编：汇编→机器码目标文件，`.o`/`.obj`；链接：合并目标文件与库，生成可执行文件。

27. **答案要点：**  
    关键字由语言保留，有固定语法含义，用作变量名会导致语法错误。示例：用 `my_int`、`ret_val` 等代替。

28. **参考代码：**
```c
#include <stdio.h>
int main(void) {
    printf("Hi\n");
    return 0;
}
```

29. **答案要点：**  
    `"my.h"` 通常先在当前/指定目录查找；`<stdio.h>` 在系统标准头文件路径查找。

30. **答案要点：**  
    接口与实现分离，便于多文件共享声明、隐藏实现、减少重复定义与链接冲突，提高可维护性。

### 三、本章知识点总结
| 要点   | 速记                    |
| ---- | --------------------- |
| 编译流程 | 预→编→汇→链               |
| 入口   | `main`，`return 0` 成功  |
| 标识符  | 字母/`_` 开头，区分大小写       |
| 文件   | `.c` 实现 / `.h` 声明     |
| 注释   | `//` 与 `/* */`，后者不可嵌套 |

## 第 2 章 · 数据类型与常量

### 本章知识点速览
- 基本类型：`char/short/int/long/long long/float/double/void`

## 第 6 章 · 指针

```c
        if (a[i] > *maxp)
            maxp = &a[i];
    return maxp;
}
```

### 三、本章知识点总结
| 写法          | 含义       |
| ----------- | -------- |
| `&x` / `*p` | 取址 / 解引用 |
| `p+1`       | 下一元素     |
| `a[i]`      | `*(a+i)` |
| `NULL`      | 空指针，勿解引用 |
| `const` 位置  | 左定值、右定针  |

## 第 8 章 · 字符串

## 第 13 章 · 动态内存

### 本章知识点速览
- `malloc`/`calloc`/`realloc`/`free` 在堆上管理内存（`stdlib.h`）
- 分配后必须检查是否为 `NULL`；`calloc` 会清零，`malloc` 不会
- 每个成功分配应有配对的 `free`；`free` 后置 `NULL`，防野指针/重复释放
- `realloc` 失败时原指针仍有效；成功后应用返回的新指针
- 泄漏：无法再访问却未 `free`；悬空：`free` 后继续使用
