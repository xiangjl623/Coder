## 目标

在 C++ 汇总学习手册的 **Guide 1～15** 中，按 C 语言手册同等形态补齐：

1. **知识点实战例题**（含解题思路与完整代码）
2. **作业练习**（可独立完成）
3. **挑战题**
4. **参考答案**（含解析过程 / 思路 + 代码）

使学习者可在手册内闭环练习，不必先翻题库才能对照答案。

## 每节目标结构

在「总结与延伸」**之前**，将现有「实战练习」区块替换为如下结构（标题层级与正文现有 `###` / `####` 一致）：

结构示意（各块均为完整 Markdown，代码用 `cpp` 围栏）：

1. `### N、知识点实战例题` — 例题含：题目、解题思路、完整代码、要点/易错  
2. `### N+1、作业练习` — 引导语 + 练习1～3 + 挑战题  
3. `### N+2、参考答案` — 每题含思路/解析 + 参考代码（纯思考题可用参考表述）

章节编号 `N` 按各 Guide 现有小节序号顺延（例如原「五、实战练习」变为「五、知识点实战例题」「六、作业练习」「七、参考答案」，原「总结与延伸」及后续卡片顺延编号）。

## 内容与风格规范

1. **标准**：示例与答案默认 `-std=c++17`；优先 `iostream`、`string`、`vector`、智能指针等现代写法。
2. **解析**：每道作业/挑战答案至少包含「思路/解析」一两段 + 可运行参考代码；例题含「解题思路」分步 +「要点/易错」。
3. **复用**：现有练习题干尽量保留意图，补清输入输出约定与完成标准；过短的思考题改为可验证的编程或简答+参考表述。
4. **一致性**：命名空间可写 `std::` 或文内已出现的 `using`；同一 Guide 内风格统一。
5. **与题库关系**：手册答案自洽；前言学习建议改为：知识点 → 例题 → 独立作业 → 本节参考答案；题库链接保留为拓展。
